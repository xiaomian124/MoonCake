# MoonCake
让你的服务器在中秋节增加更多乐趣

# 用途
中秋节快到了，这个插件能让你在服务器也能体验到中秋节的乐趣，在config.yml可以设置中秋节时间段，在中秋节时间段内击败生物（怪物、动物、水生物、蠹虫类、玩家）即可获得不同馅料的月饼，也可以通过合成获得  
合成配方：上面三格放小麦，其余格子放小麦种子，中间那格放馅料，馅料如下：  
水果(苹果)、莲蓉(睡莲)、南瓜种子/西瓜种子(五仁)、可可豆(豆沙)、鸡蛋(蛋黄)  
击败末影龙或者凋零即可获得**极品月饼**，吃下后还有增益Buff，这是极其稀有的月饼不可以合成获得  
吃下月饼还会在头顶燃放烟花以及在actionbar显示“中秋快乐！”，在中秋节开始前/结束前10秒在actionbar显示倒计时  
吃下月饼释放的烟花以及显示的“中秋快乐”会随月饼名字的颜色变化，在你捡到极品月饼时还会全服公示你捡到的极品月饼！    
生物默认是掉落月饼概率是0.2，末影龙及凋零掉落月饼概率是1.0（百分百掉落）  

指令列表：  
/mooncake news - 查看活动详细信息（仅中秋节时间段）  
/mooncake ranking - 查看月饼排行榜  
/mooncake help - 查看帮助列表  
/mooncake give <player> <mooncake> <amount> - 给予月饼（仅OP）  
/mooncake reload - 重载插件（仅OP）
